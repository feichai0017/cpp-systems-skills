原始案例见 [fixtures](fixtures/README.md)，修改文件和输入摘要见 [输入记录](smoke-inputs.json)。摘要按 SKILL.md、排序后的 references/*.md、排序后的案例文件依次拼接相对路径、NUL、原始内容、NUL，再取 SHA-256；不包含 UI 元数据或编译产物。

给执行者的任务是：使用指定 skill 完成项目 TASK，先读项目 AGENTS，限制修改在独立项目中，运行检查并报告实际结果。没有提示应删除或保留哪个实现。

| 案例 | 实际输出 | 验证 |

执行命令在各案例的项目目录运行：

```sh
# reuse
g++ -std=c++17 -Wall -Wextra -pedantic -I. operation.cc check.cc -o check
./check

# borrow / naming
g++ -std=c++17 -Wall -Wextra -pedantic check.cc -o check
./check
```

编译器为 GCC 8.3.0，三个执行者均报告无编译警告，评审者核对了源码差异和行为结果。原始案例保留初始代码，修复发生在临时副本。
