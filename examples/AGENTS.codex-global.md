## C++ 技能默认选择

- 编写、修改或重构 C++ 代码时，默认读取并使用已安装的 `cpp-core`，无需用户手动指定；本轮已读取时复用已有上下文。
- 按当前任务补充已安装的专项技能：生命周期/借用/异步/并发/SHM/I/O 回收用 `cpp-lifetime`；明确精简或删除冗余用 `cpp-simplify`；PR/MR/diff 评审用 `cpp-review`；构建或测试失败、验证方案、sanitizer/静态分析用 `cpp-validation`；性能优化与 benchmark/profiler 分析用 `cpp-performance`。
- 普通实现只使用 `cpp-core` 及其必要验证；只有涉及对应职责才加载专项技能，不一次加载全套。纯评审等非写码任务直接选择对应专项即可。
- 技能从当前技能目录定位；缺失时说明并继续能够完成的工作，不自行安装。当前用户指令和项目 `AGENTS.md`、错误策略、命名、构建约定优先。
- C++ 工程规范以 DuckDB 的贡献指南和相关实现为主要外部参考；已有项目实现优先，不照搬其异常策略、基础类型或格式配置，也不为小修改强制联网研究。
